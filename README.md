## Decisions
### 📢Atomic Design
Atomic Design was used for its benefits. It enables the development of applications with scalability and consistency. It also makes it easier to develop, maintain, and modify the behavior of each component separately.

Since this project aims to be both mobile and desktop, atomic design was also chosen because it encourages the development of components that are flexible across most available screens.

### 📢Zustand
Lightweight, flexible, non-optional, and simple. Besides being a modern alternative on the market, zustand was chosen because it encourages developers to keep application stores separate and, consequently, more organized. It follows the Flux standard. With zustand, developers don't need to manage complex logic.
